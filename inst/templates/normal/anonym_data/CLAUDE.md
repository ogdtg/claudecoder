# anonym_data/ directory

This directory contains **anonymised data only** (max 20 rows per file).
These samples are safe to read and share with Claude Code.

Important: the corresponding **real data cannot be given to Claude Code
for data-security reasons**. It lives in `real_data/`, which is
git-ignored and off limits.

Use these anonymised samples for all development and testing. The code
and functions that operate on the data live in `R/`.
